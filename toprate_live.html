Signal heatmap

Win rate of horses ranked top-1, top-3, and top-5 in each signal across all resulted races in the period. Darker green = stronger predictive power. Use this to spot which signals are working now and which have decayed.

Signal correlation

How often each pair of signals agrees on the top horse in a race. High % = signals are redundant. Low % = signals capture different information and combine well in the voting model.

Performance at each Score threshold step. Higher threshold = fewer picks but stronger conviction. Use this to set your stake threshold in Settings based on actual live data, not assumption.

Stake preferences

Unit size
Dollar value of 1 unit. Used to convert stakes/PnL between units and dollars.
Bet to return
Target gross return per bet in units (stake + profit on a winner). Stake = target / price. Volume picks are auto-halved (lower per-pick edge + higher volume).
Min stake
Minimum stake floor in units (caps very long shots). Volume picks use half this floor.
Max stake
Maximum stake ceiling in units (caps short prices). Volume picks use half this ceiling.

Cumulative score threshold

Threshold
Minimum cumulative score for a horse to qualify on the Quaddie tab. Higher = stricter, fewer picks. The score is a logistic-regression blend of TR rating, WPR, Late speed, PF AI, PF Class, and PF L600 signals (Path C). Path C scores are sigmoid-bounded in [0, 1] and tend to cluster near the middle of the range; a threshold around 0.40-0.50 matches what 0.70 used to mean for the legacy formula. The main betting model rule does not use this threshold.
WPR book %
The book the WPR prices should sum to. 100 = fair (mathematically true prices). 90 = prices are ~11% longer than fair, so fewer fixed prices count as overlays (tighter value threshold). Lower values make overlays harder to find; higher values are more generous. Default 90.
